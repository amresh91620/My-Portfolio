# 🚀 Premium Full-Stack Portfolio | Amresh Gond | Live Demo- https://my-portfolio-pi-lovat-73.vercel.app/

Welcome to my professional portfolio. This is a high-performance, visually stunning, and fully responsive web application built with a modern tech stack. Designed with a focus on **premium aesthetics**, **fluid animations**, and **clean architecture**.

## ✨ Key Features

- **Premium Design System**: A custom-built, high-contrast theme supporting both Dark and Light modes with seamless transitions.
- **Fluid Motion**: Powered by `Framer Motion` for sophisticated entrance animations, staggered lists, and interactive UI elements.
- **Glassmorphism UI**: Modern frosted-glass effects with `backdrop-blur` and dynamic shadows.
- **Responsive Navigation**: A customized mobile-first navigation system with a premium overlay menu.
- **Optimized Assets**: Custom-generated "AG" branding and integrated PDF resume download.
- **SEO Optimized**: Semantic HTML5 structure with proper metadata.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Playfair Display (Serif) & Inter (Sans)
- **Deployment**: [Vercel](https://vercel.com/)

## 📂 Project Structure


## 🚀 Local Development

1. **Clone the repository**
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Start the development server**
   ```bash
   npm run dev
   ```
4. **Build for production**
   ```bash
   npm run build
   ```

## 🌍 Vercel Deployment

This project is optimized for deployment on **Vercel**.

1. **Push your code to GitHub.**
2. **Import the project in Vercel.**
3. **Configuration**:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. **SPA Routing**: A `vercel.json` file is included to handle client-side routing automatically.
